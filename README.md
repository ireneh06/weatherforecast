# Aurelia Frontend and ASP.NET Web API Backend Project

This project combines an **Aurelia frontend** with an **ASP.NET Web API backend**.

---

## Prerequisites

- **Node.js:** v20.17.0
- **cmd**: node -v

- **npm:** Comes with Node.js, install all dependencies
- **Visual Studio 2024 or later** (for the backend)
- **.NET SDK:** 9.0.101 
- **cmd:** dotnet --version
- **Aurelia CLI:** Required to build and run the Aurelia frontend
---

## Setup Instructions

### 1. **Open Backend-Folder **
- Navigate to the backend project folder:
- C:\HTL\SWP\WeatherForecast_Hofer_Irene\02_WeatherForecast\02_WeatherForecast
- Alternatively, open the folder in a terminal:
- Open the File Explorer and go to the folder. In the address bar, type cmd and press Enter to open the terminal in the current folder.
### 2. **Run Backend project**
- Start the backend project using the .NET CLI:
- command: dotnet run
- Backend starts and is accessible at: 
- http://localhost:5118
### 3. **Open Frontend-Folder **
- Navigate to the backend project folder:
- C:\HTL\SWP\WeatherForecast_Hofer_Irene\04_Weatherforecast
### 4. **Run Frontend project**
- Start the frontend using the Aurelia CLI:
- command: au run
- Frontend starts and is accessible at: 
- http://localhost:9090/
